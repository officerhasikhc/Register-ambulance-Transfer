# مجلد الأصول (Assets)

## قالب كشف حركة سيارات الإسعاف (PDF)

ضع هنا ملف PDF الرسمي **بعد** تسمية حقوله في Adobe Acrobat (Prepare Form) كما في الملف:

**`../PDF-FIELD-NAMES.md`**

- **اسم الملف المطلوب:** `ambulance-form-template.pdf`
- بعد وضعه هنا، زر «تنزيل كشف PDF» في لوحة الإدارة سيعبئ هذا القالب من الرحلات المكتملة للفترة المحددة ويُنزّل الملف.

إذا استخدمت اسماً مختلفاً للملف، غيّر ثابت `PDF_TEMPLATE_URL` في `admin-interface.html` ليشير إلى المسار الصحيح (مثلاً `assets/كشف-حركة-سيارات-الاسعاف.pdf`).
